iOS personal-finance app

Financier

A privacy-first personal finance ledger. Single-user, sideload-only, with a self-hosted backend on the user's home network and on-device AI via Apple Intelligence.

Read-only by design

The app aggregates account balances, transactions, and liabilities. It cannot transfer money, initiate payments, or modify any data at the bank. Plaid's read-only product scopes (transactions, liabilities) are the only ones requested.

No third-party data sharing

Bank data flows: bank → Plaid → user's self-hosted backend → user's iPhone. The backend runs on the user's hardware. The iPhone uses CloudKit's private database (visible only to the user's Apple ID). No analytics, no telemetry, no third-party cloud.

Encryption at rest

Plaid access tokens on the backend are stored in an age-encrypted file. The iPhone uses iOS Data Protection (Complete) for all SwiftData state. The TLS channel between the iPhone and the backend is pinned via SHA-256 of the leaf certificate.

Distribution: Sideloaded to the developer's own iPhone via Xcode using a paid Apple Developer profile. Not on the App Store. No external users.
